# RoboSTAR project-page assets

Replace the placeholder files below while keeping the same filenames:

- `robostar_logo.png`: square logo; transparent PNG recommended.
- `teaser.png`: main teaser image; recommended aspect ratio 16:9 or 2:1.
- `method.png`: architecture/method figure; a wide landscape image works best.
- `results.png`: qualitative results or real-robot montage.

The demo video is currently embedded from the GitHub user-attachment URL already used in the repository README. To host it locally instead, place `demo.mp4` here and replace the `<source>` URL in `../index.html` with `assets/demo.mp4`.
